# Windows qualification record

The v0.2 Windows qualification record is maintained in [V0_2_WINDOWS_QUALIFICATION.md](V0_2_WINDOWS_QUALIFICATION.md). This compatibility file remains for links from earlier v0.1 documentation.

The authoritative procedure is [WINDOWS_TESTING.md](WINDOWS_TESTING.md). A real result requires an interactive Windows desktop, a configured live Gateway model, the native .NET sidecar, the installed OpenUse build, and operator-confirmed visible outcomes. Protocol tests, browser previews, cross-builds, and a responsive installed process are not task qualification.
